# YORIMICHI QUEST（ヨリミチ・クエスト）

> 市民の「寄り道」が都市の安全データを創る、協創型・防災ゲーミフィケーションプラットフォーム

日常の散歩や寄り道で位置情報ゲームを楽しむうちに、避難ルートと防災知識が身につき、行政オープンデータに不足している防災・バリアフリーのミクロデータが集まる — 平時と有事のデュアルモードで動く LINE ミニアプリです。収集データは自治体標準オープンデータセット準拠で行政へ還元します。

**都知事杯オープンデータ・ハッカソン2026 応募プロジェクト**

## サービス概要

| モード | 概要 |
| :--- | :--- |
| 平時モード | 避難所チェックイン、現地クイズ、写真投稿ミッション。投稿写真は Vision AI がバリアフリー属性を自動解析・構造化 |
| 有事モード | 災害時にライフライン案内へ切替。蓄積データをもとに避難所・水・電源・バリアフリー情報をマップ案内 |
| 行政還元ダッシュボード | データ空白地帯・優先整備箇所を可視化し、CSV でオープンデータとして還元 |

## 技術スタック

- **提供形態**: LINE 公式アカウント（入口・プッシュ通知）＋ LINE ミニアプリ / LIFF
- **フロントエンド**: React + TypeScript、Mapbox GL JS または Leaflet（マップは未確定）
- **バックエンド**: enebular クラウド実行環境（ZIP / Node.js 22.x）＋ Hono
- **データストア**: enebular データストア（KVS。エリア単位のパーティション設計）
- **ストレージ**: CUCON（S3）／投稿写真
- **AI エージェント**: Dify Cloud + Gemini（画像属性抽出・不適切判定・クイズ生成をアプリとして開発し、App API 経由で呼び出す）
- **ダッシュボード**: 同一 ZIP の別パスで配信（閲覧専用）

選定が未確定の項目（マップライブラリ、収集する防災データ項目の定義）は Issue で管理しています。
