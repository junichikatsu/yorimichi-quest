# オープンデータ取込（FR-10）

千代田区・港区の公開オープンデータを取得して正規化し、
`apps/function/src/data/opendata-spots.ts` を生成します。

```bash
pnpm ingest
```

**ネットワークへ出るのはこのスクリプトだけです。** 関数側は生成済みのファイルを読むだけなので、
デプロイ先から外部へ取りに行きません。避難所CSVは 13.8MB あるため、実行時に落とす作りにはしていません。

## 取り込むデータ

| カテゴリ | 出典 | 形式 | 千代田区 | 港区 |
| :--- | :--- | :--- | :--- | :--- |
| 避難所・避難場所 | 東京都総務局 | CSV（CP932） | 14 | 58 |
| 給水スポット | 東京都水道局 | CSV（CP932） | 11 | 27 |
| バリアフリートイレ | 千代田区 | CSV（UTF-8 BOM） | 36 | **未公開** |
| AED | 港区 | GeoJSON | **未公開** | 224 |

**2区にしているのは、片方だけでは4カテゴリが揃わないためです**（#6）。
千代田区に AED が無く、港区に公衆トイレがありません。

URL・文字コード・列名の定義は [sources.mjs](sources.mjs) に集めてあります。コードに散らしていません。

## 撮影ルートに合わせて絞り込む

全件だと 370 件で、`MAX_SPOTS_PER_REQUEST`（既定 200）を超えます（FR-10-4）。

```bash
# 中心から半径 1200m に絞る
pnpm ingest -- --center 35.669,139.753 --radius 1200

# AED だけ 60 件に制限（--center があれば近い順に採用）
pnpm ingest -- --center 35.669,139.753 --cap aed=60
```

**落とした件数は必ず出力します。** 黙って切り捨てると、全件入っているつもりで地図が欠けます。

## その他の引数

| 引数 | 意味 |
| :--- | :--- |
| `--offline` | ダウンロードせず `.cache/` だけで実行する |
| `--out <path>` | 出力先を変える |

## 設計上の判断

**スポットIDは出典・名称・座標のハッシュです。** 連番にすると、上流の行順が変わるだけで
別のスポットになってしまいます。場所カード（FR-14）の達成記録がIDに紐づくため、
IDが動くと収集済みが消えます。

**属性の空欄は取り込みません。** 空欄は「設備が無い」ではなく「未記入」です。
記入済みの値だけを `attributes` に入れています。**この空欄そのものがクエストの対象になります**（FR-12）。

実測した空欄の例：

- 避難所72件のうち、スロープと点字ブロックの欄が空なのが各26件、車椅子対応トイレが11件
- 千代田区の公衆便所は「車椅子使用者用トイレ有無」が**37件すべて空欄**（オストメイトは33件記入済み）
- 港区のAEDは属性が「施設名」「所在地」しか無く、屋内か屋外か・24時間使えるかが分からない

**座標が使えない行は落とし、理由を出力します。** 実測では、千代田区の錦華公園が緯度経度未記入、
港区のAEDに箱根町の保養施設が2件混ざっていました。

## ライセンス

**出典表示が必要です。** 画面のフッタに出典と取得日を表示しています（`DataCredits`）。
表示は畳めますが、消せる作りにはしていません。

各自治体の利用規約の個別確認は未実施です（`doc/opendata-sources.md` のチェックリスト参照）。
