# YORIMICHI QUEST 戦闘要素の概要（導入検討用メモ）

> 市民の「寄り道」が都市の安全データを創る、協創型・防災ゲーミフィケーション

> このメモは検討用の概要です。**戦闘要素の採用可否は未定**です。
> 元資料（Word）を Markdown 化したものです。

## 1. ねらい

戦闘要素のねらいは、遊びをそのまま防災学習に変えることにある。街を歩いて防災スポット（避難所・AED・給水拠点など）を点検すると、その場所に紐づいた「災害の擬人化キャラ」が敵として現れ、防災クイズに答えて撃破する。戦闘がそのままクイズになっているため、戦うほど防災知識が身につく構造になっている。

## 2. 敵は災害の4系統

敵は災害を擬人化した4系統で構成する。どの敵が出るかは場所と連動しており、「敵が出やすい場所＝現実に注意すべき場所」になるよう設計する。これにより、遊びながら自分の生活圏のリスクを体で覚えられる。位置情報ゲームにおける、このプロダクト固有の強みである。

| 敵の系統 | 対応する場所の例 | 問われる知識 |
| :--- | :--- | :--- |
| 水 | 浸水想定エリア・川沿い・低地 | 冠水時の移動、車の水没回避など |
| 火 | 木造住宅が近い一帯 | 地震直後の初期対応、延焼への備え |
| 停電 | 夜間や停電時に頼る場所 | 裸火を避ける、スマホの節電など |
| デマ | 人と情報が集まる場所 | 公式での確認、拡散の抑制など |

## 3. 戦闘の流れ

1. スポットに到着し、点検内容を報告する。
2. その場所に対応した災害の敵が出現する。
3. 防災クイズ1問に回答する（敵の系統ごとに出題カテゴリが対応）。
4. 正解で敵を撃破。正解・不正解のどちらでも必ず解説が表示される。

間違えてもペナルティはなく、解説を読んで再挑戦できる。「間違えても学べる」ことを最優先にした、防災アプリらしい設計である。

## 4. 報酬とアイテム・装備

点検の報告時と敵の撃破時に、アイテムが必ずドロップする。アイテムは実在の防災グッズ（ヘルメット、レインコート、防災ラジオなど）で、その効果は道具の現実の役割に対応している。

- **ヘルメット** … 落下物から頭を守る（防災力アップ）
- **レインコート** … 雨と浸水から体を守る（回答時間に余裕）
- **ヘッドライト** … 停電時に灯りを確保する（クイズの選択肢が減る＝ヒント）
- **防災ラジオ** … 正しい情報を受け取る（防災力・回答時間アップ）

集めた装備はキャラクターの見た目に反映され、「防災リュック」画面で一覧・付け替えができる。装備を集めること自体が、防災備蓄リストを学ぶことにつながる。

## 5. この仕組みの意義

位置情報ゲームにありがちな「ただ集めて戦う」で終わらせず、戦闘・収集・見た目の変化のすべてを防災の学びと備えに結びつけている点が要である。当初コンセプトである「平時に遊びながら学び、有事に活きる」という背骨を、戦闘要素が具体的に裏打ちする。

## 6. 導入にあたっての注意点

- 災害の擬人化は表現を誤ると被災された方を傷つける。特定の災害や被災地を想起させない、抽象的なデザインにする必要がある。
- 報酬目当てで危険な場所へ人を誘導しないこと。浸水エリアや川沿いで敵を出す場合も、「近づいて戦え」ではなく「ここは危ないと学べ」という文脈に必ず着地させ、悪天候時や実際に危険な状況では出現を抑える安全設計を前提とする。
- 戦闘や収集を強くしすぎると、本来集めたい「街の安全データ」より敵狩りに関心が向くおそれがある。データ収集と戦闘報酬のバランス設計が求められる。

## 7. まとめ

戦闘要素は「防災クイズによる学習」を軸に、「場所と連動した敵」「実在グッズの収集と装備」を組み合わせたもので、防災の学びと備えを遊びの中に自然に埋め込む仕掛けである。導入するかどうかは、上記の表現・安全・バランスへの配慮とあわせて判断するのがよい。
