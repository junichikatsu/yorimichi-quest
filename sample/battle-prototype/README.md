# サンプル: battle-prototype（戦闘要素のプロトタイプ）

YORIMICHI QUEST の**コンセプト確認用プロトタイプ**です。**正式な開発ではありません。**
他のサンプルとは独立しています（[サンプル一覧](../README.md)）。

`map-checkin` のようなビルドが必要なワークスペースではなく、**単一 HTML ファイルの静的プロトタイプ**と、
その背景にある企画メモをまとめた「見た目・体験の確認用」サンプルです。

## 中身

| ファイル | 内容 |
| :--- | :--- |
| [index.html](index.html) | 実地図デモ。スマホ枠の中で「冒険者づくり → 実地図（MapLibre）→ 防災リュック」までを通しで見られる HD-2D 風プロトタイプ |
| [combat-overview.md](combat-overview.md) | 戦闘要素の企画メモ。敵＝災害4系統／防災クイズ＝戦闘／実在グッズのドロップと装備。**採用可否は未定** |

## 動かし方

ビルド不要です。`index.html` をブラウザで開くだけで動きます。

```bash
open sample/battle-prototype/index.html
```

- 地図タイルは **MapLibre GL JS を CDN から動的読み込み**します。ネットワークが無い／読み込みに失敗した場合は、
  オフライン用の簡易マップに自動フォールバックするため、本体は動き続けます。
- スマホ実機で見るときは、簡易サーバー経由が確実です（例: `npx serve sample/battle-prototype`）。

## 注意（このサンプルの位置づけ）

- **プロトタイプ**です。バックエンド・認証・永続化はありません。表示データはすべて**デモ用の架空データ**です。
- `combat-overview.md` の戦闘要素は**検討段階**で、実装するとは決まっていません。
- 災害の擬人化は表現次第で被災された方を傷つけます。導入を検討する場合は
  `combat-overview.md`「6. 導入にあたっての注意点」の配慮を前提にしてください。
