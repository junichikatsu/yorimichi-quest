## 中心的な発見：場所は知られているが、中身は知られていない

| 設問 | 結果 |
| :--- | :--- |
| 最寄りの避難所の場所が浮かぶ | **25/37（67.6%）** |
| 避難所について場所以外の情報（水害対応・混雑状況・トイレ設備など）を知っている | **6/37（16.2%）** |
| **場所が浮かぶ25人のうち、場所以外を知らない** | **19/25（76.0%）** |

**約7割が避難所の場所を知っているのに、中身を知っているのは6人に1人以下。** 場所を知っている人に限っても、その76%が「名前しか知らない」状態である。

これは要件定義書 1.1 の課題1（ミクロデータの圧倒的不足）が、行政側のデータ不足であると同時に**市民側の情報空白として実測できた**ことを意味する。P-1（行政データの不足を補う）が解こうとしている対象が、この19人である。

### 「検索して困った」の具体（原文）

- **「大雨洪水警報が出た際、避難所を検索して、行ってみたら開いていなかった。」**

- 「どの交通手段が生きているか、しんでいるか、遅れはどれくらいか、原因は？とわからないことだらけで、困りました」
- 「主に『X』で情報収集するが、障害などがあると情報を集められない／テレビやラジオが家にないため、インターネットの回線が弱いと情報を収集できない」

- 「そもそも繋がらない」

1件目は**開設状況という項目が存在しないことによる実害**の報告である。データ辞書（FR-12-1 / #14）に「開設状況」を含める根拠として、この1文がそのまま使える。

## 要配慮者の困りごとは、当事者にしか見えていない

| 層 | ベビーカーや車椅子で「通れるか不安で遠回りした」経験 |
| :--- | :--- |
| 未就学児または要配慮者がいる（10人） | **6/10（60.0%）** |

**該当者では6割が経験しているのに、非該当者では1件も発生していない。** 困りごとが当事者層に完全に閉じている。

これは2つのことを示す。第一に、ペルソナ④（要配慮者の家族）の課題は実在する。第二に、**当事者以外には見えないため、行政も把握しづらく、オープンデータにも現れない**。「情報が不足している」ことの構造的な理由がここにある。

ソーシャルインパクト（都民のQOL向上）を「行ける場所が増える」で語る根拠もこの数字である。

## 行政からの情報は届いていない

| 設問 | 結果 |

### 寄り道 24.3% の解釈

サービス名に冠している「寄り道」は、**自然発生では4人に1人しか起きていない**。この数字は都合が良くないが、理由の自由記述を読むと解釈が変わる。

- 「なんとなく別の道を通ってみた」
- 「気分転換にルートを変えた」
- 「景色を楽しみたいから」
- 「たまには違うルートで散歩をしてみよう！となりました」
- 「公園、気分転換」

寄り道した9人の動機は、いずれも**目的がなく軽い**。つまり寄り道は「強い動機がある人だけの行動」ではなく、**きっかけがあれば起きる行動**である。

したがってこの数字は「寄り道する人が少ない」ではなく、**「寄り道のきっかけが街に存在していない」**と読むべきである。きっかけを供給することがサービスの提供価値であり、24.3% という低さはむしろ余地の大きさを示す。ピッチでもこの順序で語る。

## 自由記述に現れた懸念（分類）

| 分類 | 件数 | 代表的な記述 |
| :--- | :--- | :--- |
| **備えが不十分・後回しになっている** | 6 | 「準備が万全ではないけど、かといってどうしようという計画もないこと自体が不安」「家具の固定などやらないとなーと思いつつ、後回しになっている」 |
| **避難所の中身が分からない** | 5 | 「実際に避難所に避難した場合に、どういった設備があるのか？食料は何日分まかなえるのか。水は？」「避難所の物資やトイレの在庫、水が使えるかなど」「水、電源、パーソナル空間」 |
| 家族の分散・連絡手段 | 3 | 「家族がバラバラな時の行動がその時の判断になるのが懸念」「離れて暮らしている両親が避難できるかどうか」 |
| ペット同伴避難 | 2 | 「避難所に猫を大量に連れて行けないので、諸々備蓄はしてます」「猫がいるので避難所での生活が難しい気がしており」 |
| 自宅エリアの安全性が分からない | 2 | 「自分の住んでいるエリアが安全なのか、あまり理解できていないことへの問題意識がある」 |
| 乳幼児対応 | 1 | 「幼児がいるため、離乳食など避難時にあるのか不安」 |

**最多は「備えが不十分（6件）」で、次が「避難所の中身が分からない（5件）」。** 前者は P-2（防災意識を上げる）、後者は P-1（データの欠損を埋める）の対象であり、要点2つが自由記述の上位2分類に対応している。

### データ辞書（#14）へ直結する記述

以下は収集項目の候補としてそのまま使える。

- 開設状況（「行ってみたら開いていなかった」）
- 備蓄物資・食料の日数、飲用水の可否、トイレの在庫・使用可否
- 電源の有無
- パーソナル空間・プライバシーの確保状況
- ペット同伴の可否
- 乳幼児対応（離乳食・ミルク）
- 「避難所のアイコン設置有無」（現地に表示があるか）

## サービスへの要望（自由記述）

- 「居住地のみではなく、出先でも登録など不要で簡単に使えると嬉しいです。」→ LIFF による未登録利用に近い体験、および現在地ベースの動作（FR-02-1）の裏付け
- 「ITリテラシが高くないヒトでも容易に情報にアクセスできるようにして欲しい。（口頭入力など）」→ G-3（一般性を優先しゲーム性を手加減する）、NFR-08（アクセシビリティ）の裏付け
- 「防災意識が低いことを実感しました。」→ アンケートに答えるだけで自覚が生まれている。P-2 の「無意識のうちに学習する」という設計方針が機能しうる兆候

## この調査で埋まっていない穴

| 穴 | 内容 |
| :--- | :--- |
| **初期ターゲットが含まれていない** | 回答者は一般都民であり、防災士・消防団員（フェーズ1／要件定義書 4.1）は含まれない。**#17 で指摘した「初期ターゲットへの CPF 未実施」は解消していない**。本調査はフェーズ2（一般層）の CPF を埋めたものと位置づける |
| **シニア層が2人しかいない** | 60代が2人、50代が3人。ペルソナ③（アクティブシニア・60-70代）の検証はできていない |
| ゲーム性への反応は聞いていない | 設問にゲーム要素・報酬・SNSシェアに関する項目がない。PSF 検証（要件定義書 5.1）で別途確認が必要 |
| 東京都民に限定されていない | 回答者の居住地を確認していない。「土砂崩れの危険性のある実家」「汽車」など都外を示唆する記述がある |
